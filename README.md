## Что сделано

Это консольный проект по первому занятию — «Классы». В нём реализована небольшая модель профиля пользователя и сервис для работы с профилями.

### Задание 3

Реализованы классы:

- `User` — пользователь с ID, ФИО, логином и хэшем пароля;
- `CommunicationChannel` — канал связи с ID и именем;
- `Contact` — контакт с ID, каналом связи и идентификатором;
- `UserProfile` — профиль, объединяющий пользователя и коллекцию контактов;
- `UserProfileService` — создание профилей, изменение ФИО, добавление контактов и получение краткой статистики через деконструктор.

В примере создаётся профиль, к нему добавляются почта и мессенджер, после чего выводится короткая статистика.

## Ожидаемый результат

Программа создаёт профиль пользователя, добавляет к нему два контакта, выводит краткую статистику и список контактов.

## Что пришлось решить по ходу работы

1. Одного контакта для нормального примера мало, поэтому профиль хранит коллекцию. Снаружи её можно читать, но нельзя подменить.
2. Открытый пароль в модели хранить неправильно. Здесь есть только `PasswordHash`; само хэширование не относится к этой работе.
